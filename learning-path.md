# Learning Path

A staged route through this playbook and its [library](resources/README.md),
for a reader starting from zero — maybe not yet knowing what GitHub is —
who wants to end up *using* AI for their own projects, the way this
playbook's author does.

Move at your own speed. Each stage says what it is for, what to read and
do, the practice that makes it stick, and how to know you are ready for the
next one. You can stop after any stage and already be ahead.

## Stage 0 — Start where you are

**For:** the picture, before any machinery.

- Read [Article 001 — Onboarding a Personal Agent](articles/series-1-the-personal-agent/001-onboarding-a-personal-agent.md).
- Skim the [glossary](glossary.md) and the [patterns](patterns.md).

**Practice:** start one real, reversible task with any AI assistant this
week — email, a summary, a plan.
**Ready when:** you can say, in your own words, what an *agent* is, what
*context* means, and why one room per project helps.

## Stage 1 — Understand the machine

**For:** what a large language model actually is and does.

- Work through **AI for Beginners** at your own pace.
- Add **Generative AI for Beginners** for the applied side.
- If you like learning by code, run the notebooks in **Dive into LLMs**.

**Practice:** run at least one lesson's code yourself and change one thing
in it.
**Ready when:** you can explain what the model is doing when it answers
you — and what it is *not* doing.

## Stage 2 — Understand agents

**For:** how an assistant becomes an agent: loops, tools, memory, planning.

- Read the **AI Agent Book**, a chapter at a time, with its code.
- Re-read this playbook's Series 1 as you go — the story and the theory
  illuminate each other.

**Practice:** sketch, on paper, the loop of an agent you would want:
what it perceives, decides, does, and remembers.
**Ready when:** you can name where tools, memory, and human approval plug
into that loop.

## Stage 3 — Build your first agents

**For:** turning understanding into running software.

- Start with the **OpenAI Agents SDK** — the smallest path to an agent of
  your own.
- Keep the **OpenAI Cookbook** open beside you.
- Graduate to **LangGraph** when your agent needs steps, state, memory, or
  approval gates.

**Practice:** one small agent, doing one real job end to end — yours, not a
tutorial's.
**Ready when:** it runs, it helps, and you know exactly where it can go
wrong.

## Stage 4 — Connect, own, and package

**For:** the layer this playbook itself is about — context, connection, and
reuse.

- Get workspace intuition from **AnythingLLM** with your own documents.
- Learn how agents reach the world through **MCP servers**.
- Study how capabilities are packaged in **Agent Skills** — then return to
  this playbook's Series 2–4 (project management, ministry operations,
  learning by building) and, in time, its [skills shelf](skills/README.md).

**Practice:** package one thing you taught your agent as a reusable set of
instructions someone else could run.
**Ready when:** another person — or another agent — can reuse what you
built without you in the room.
