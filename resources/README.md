# Resources — the library

The playbook's knowledge base: external repositories, books, and courses
that serve the same purpose — helping people use AI for their own projects.
Curated, not comprehensive. A resource earns its place by being durable,
maintained, and honest teaching material — most of it learning-by-practice,
like the playbook itself.

Paul seeded this list on 2026-10-30; his agent added four more the same day
(marked ✦). Additions follow the same bar and are recorded in STATE.md.

## Foundations — understand the machine

- **[AI for Beginners](https://github.com/microsoft/AI-For-Beginners)**
  (Microsoft) — *Beginner.* A 12-week, 24-lesson curriculum covering AI for
  everyone, gently. **Why it's here:** our readers start from zero; this is
  the friendliest full foundation we know.
- **[Generative AI for Beginners](https://github.com/microsoft/generative-ai-for-beginners)**
  (Microsoft) ✦ — *Beginner to builder.* 21 lessons on building with
  generative AI — prompting, apps, and agents in embryo. **Why it's here:**
  the applied companion to the theory above.
- **[Dive into LLMs](https://github.com/Lordog/dive-into-llms)** (Lordog) —
  *Beginner to builder, hands-on, in Chinese.* Programming-practice
  tutorials on how large language models actually work. **Why it's here:**
  it teaches the way this playbook learns — by doing.

## Agent concepts and design

- **[AI Agent Book](https://github.com/bojieli/ai-agent-book)** (Bojie Li) —
  *Builder, in Chinese.* A complete book on AI agents — design principles
  and engineering practice — with full text, a compiled PDF, and code for
  every chapter. **Why it's here:** the systematic treatment of the thing
  Series 1 and 2 of this playbook are about: what an agent is, and how it
  should be built.

## Frameworks — build agents of your own

- **[OpenAI Agents SDK](https://github.com/openai/openai-agents-python)**
  (OpenAI) — *Builder.* A lightweight, powerful framework for multi-agent
  workflows, in Python. **Why it's here:** the smallest honest path from
  "I understand agents" to "an agent of mine is running."
- **[LangGraph](https://github.com/langchain-ai/langgraph)** (LangChain) —
  *Builder to advanced.* Build resilient agents: stateful, multi-step
  workflows with memory and human-in-the-loop points, drawn as graphs.
  **Why it's here:** when one agent grows into a workflow — the same shape
  as this playbook's rooms, gates, and handoffs.
- **[OpenAI Cookbook](https://github.com/openai/openai-cookbook)** (OpenAI)
  ✦ — *Builder, reference.* Examples and guides for using the OpenAI API.
  **Why it's here:** recipes to keep open beside you while you build.

## Tools, workspaces, and connection

- **[AnythingLLM](https://github.com/Mintplex-Labs/anything-llm)**
  (Mintplex Labs) — *Beginner to builder, no code needed.* A local-first,
  all-in-one AI application: chat with your documents, build workspaces,
  run agents — your intelligence, owned by you. **Why it's here:** it gives
  hands-on intuition for context and workspaces before you build anything,
  and it shares this playbook's conviction that your data stays yours.
- **[Model Context Protocol Servers](https://github.com/modelcontextprotocol/servers)**
  (MCP) ✦ — *Builder.* Reference servers for the Model Context Protocol,
  the open standard for connecting agents to tools and data. **Why it's
  here:** connectors are how a personal agent reaches email, calendars,
  and repositories; this is that layer, in the open.

## Skills — package what works

- **[Agent Skills](https://github.com/anthropics/skills)** (Anthropic) ✦ —
  *Builder.* The public repository of Agent Skills: reusable capabilities
  packaged as instructions an agent can load. **Why it's here:** it is the
  canonical example of the thing this playbook's own [skills shelf](../skills/README.md)
  will one day publish — lessons turned into tools.
