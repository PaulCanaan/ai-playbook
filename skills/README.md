# Skills

This is the shelf where **skills** will be published.

A **skill** is a reusable, step-by-step capability: a packaged set of
instructions (and sometimes scripts) that teaches an AI agent how to do one
job well — the same way, every time, for anyone who uses it. Where an
article in this playbook tells the story of a lesson, a skill is the lesson
turned into a tool.

## What will live here

Skills that grew out of the journey in [articles/](../articles/) — each in
its own folder:

```text
skills/
└── <skill-name>/
    ├── SKILL.md     the instructions an agent follows
    └── README.md    what it does, in plain words, for humans
```

## The publishing rule

A skill is published here only after it has worked in a real project — the
same standard this playbook applies to everything: experience first, then
sharing.

*No skills are published yet. The first ones will grow out of Series 1–4.*
